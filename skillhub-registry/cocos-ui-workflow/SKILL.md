# Cocos Creator UI 工作流

## 适用场景
- 游戏活动 UI 批量生成
- 配置表自动化导入
- Prefab 结构标准化
- UI 资源压缩与优化

## 使用步骤
1. 策划提供活动文档
2. 需求分析 Agent 拆解 UI 清单
3. 自动生成 Prefab 节点树
4. 配置表 Excel → JSON/TS 转换
5. 资源压缩与 Atlas 打包

## 配置要求
- Cocos Creator 3.8+
- Node.js 16+
- Python 3.8+ (用于打表)
